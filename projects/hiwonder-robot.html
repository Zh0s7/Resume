Autonomous Mobile Manipulator

Multisensor localization, navigation, and manipulation

Perception and control software on a Hiwonder MasterPi, combining camera localization, ultrasonic depth measurements, PID navigation, and arm integration.

Existing hardware platform

The MasterPi provides a Raspberry Pi, a four-wheel Mecanum drivetrain, a servo-actuated multi-joint arm, a gripper, an RGB camera, and an ultrasonic sensor. The engineering work centers on software and control integration using that hardware.

Navigation and perception

Python and OpenCV implement HSV color processing, contour and centroid extraction, PID line tracking, autonomous movement, ultrasonic obstacle detection, and avoidance routines. Path-planning development forms another workstream.

The RGB camera identifies objects and estimates image-plane positions. Ultrasonic measurements supply distance information to complement the camera’s limited monocular depth information.

Localization and manipulation

Visual centroid information and ultrasonic distance measurements are combined to estimate a target position for the robotic arm. Kinematics maps target coordinates to joint positions.

The arm uses initial sensor measurements before executing its motion. Continuous camera-based trajectory correction is outside the implemented approach. Individual manipulation performance still needs documentation.

Filtering and individual contribution

Sliding-window ultrasonic filtering uses Python data structures such as deques to improve handling of unreliable distance readings.

Within the four-person team, I completed the majority of development and contributed across navigation, PID control, vision, localization, filtering, kinematics, arm integration, physical testing, and debugging.

Infernal Labyrinth

Procedural C++ dungeon crawler and persistent encounters

A terminal dungeon crawler connecting procedural rooms, deferred enemy encounters, turn-based combat, and riddle-driven progression.

System architecture

The C++ source, dungeonCrawler.cpp, defines entity structures with health, damage, name, and danger level, and a room_t structure with topology and room-generation behavior.

Corridors branch into one to three doors. A pool of 52 mythological creatures supplies randomized encounters. The initial boss encourages retreat, exploration, and later rematch.

Deferred encounters

The Quick Fight system preserves an enemy’s current state in a dynamic std::vector when the player retreats. A player can inspect, select, retrieve, remove, and rematch saved encounters.

This preserves state during the current program runtime. Combat uses randomized attack, defend, and idle states with danger-based priority and mathematical progression.

Riddles and input handling

Twenty-five riddles award five to fifteen upgrade points per prize room. Input is normalized, solved riddles are removed to avoid repetition, and upgrades recalculate character statistics.

Exception-handled std::stoi parsing, numeric validation, vector helpers, and string processing handle malformed terminal input. Development date and exact ownership remain to be confirmed.

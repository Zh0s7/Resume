Self-hosted AI and multi-node computing infrastructure

Computing architecture

AI model inference runs exclusively on the Raspberry Pi. Repurposed server nodes host separate workloads through Kubernetes and containerized services.

The supporting environment uses Ubuntu Server, Arch Linux, networking, private networking, and SSH administration. This architecture separates resource-constrained local inference from other hosted tasks.

Implemented work

I independently configured the infrastructure, Linux servers, Kubernetes environment, networking, Raspberry Pi AI deployment, and system integration.

A working Python speech-to-text interface translates spoken input into text for interaction with the assistant. The currently deployed language model and runtime still require confirmation.

Future objectives

File interaction, persistent conversation memory, software development assistance, GitHub integration, task execution, camera perception, model switching, and text-to-speech remain future or unconfirmed capabilities.

Verification limits

Cluster scale, service counts, uptime, and VPN-traffic metrics need reconfirmation before they can describe this project. Runtime specifications and performance figures are awaiting documentation.

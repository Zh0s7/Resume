RISC-V RV32I Processor Emulator

Instruction execution and processor state in C

A C software emulator exploring instruction decoding, registers, arithmetic, control flow, and processor memory state.

Engineering objective

The emulator investigates how binary instructions are decoded and executed and how processor state changes during program execution. Low-level C models fundamental processor behavior.

Previously documented implementation

Implementation areas include instruction decoding, register reads and writes, arithmetic and logical operations, a software ALU, program-counter management, branching, memory addressing, loads/stores, and memory-mapped I/O.

The complete implemented instruction subset needs verification against the source. ISA conformance and supported program formats remain to be documented.

Validation and documentation

Original benchmark methodology and test results have yet to be recovered. Throughput and validated-program counts are therefore awaiting reconfirmation.
